# 함께 돌봄

심방사역자와 새가족위원이 함께 쓰는 사역 수첩(웹앱)입니다. 휴대폰·컴퓨터에서 주소를 열고, 관리자에게 받은 **이름과 코드**로 로그인합니다.

## 주소

| 누가 | 주소 | 들어가면 |
|---|---|---|
| 심방사역자 | https://mokyangdesk-lang.github.io/hamkke-dolbom/?for=visit | 이름+코드 → 심방 화면(오늘 할 일·교구 성도·문자·주간 보고) |
| 새가족위원 | https://mokyangdesk-lang.github.io/hamkke-dolbom/?for=new | 이름+코드 → 새가족 화면(현황판·문자·주간 보고) |
| 관리자 | https://mokyangdesk-lang.github.io/hamkke-dolbom/?for=admin | 이메일 로그인 → 관리 화면(담당자·교구·명단·매칭·배정·예문·테마) |
| 교구 목사 · 새가족팀 | https://mokyangdesk-lang.github.io/hamkke-dolbom/ | 이름+코드 → 맡은 범위의 화면 |
| 사용 안내(설치법·자주 묻는 질문) | https://mokyangdesk-lang.github.io/hamkke-dolbom/guide/ | 누구나 |

- 주소는 달라도 **같은 앱**입니다. 어떤 화면이 열릴지는 주소가 아니라 **받은 코드**가 정합니다(서버가 판정). 다른 역할의 주소로 들어와도 자기 화면만 열립니다.
- 홈 화면(바탕화면)에 추가해서 앱처럼 씁니다. 따라 하기는 사용 안내에 있습니다.

## 자료와 개인정보

- 기록은 교회가 직접 만든 Supabase 서버에 저장됩니다. 각자의 구글 계정에 저장하는 방식과 다릅니다.
- 이 저장소에는 앱 화면 코드와 공개해도 되는 서버 주소·공개 키만 있습니다. 성도 자료와 비밀 키는 없습니다.
